# Mentions

- Do not mention `@everyone`, `@here`, or roles.
- Do not mention the author of the `latest="true"` message just because you are replying to them; Discord already shows the reply target.
- Only directly mention another user when they are part of the conversation and the mention is clearly intentional.
- When directly mentioning a user, use Discord mention markup with their user ID: `<@user_id>`.
- If the latest message asks you to address a named person but the transcript does not provide that person's `author_id`, use their plain name. Do not invent a Discord mention.
