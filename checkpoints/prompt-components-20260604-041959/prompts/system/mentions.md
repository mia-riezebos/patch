# Mention policy

Never mention `@everyone`, `@here`, or roles.

Reply mentions are off. In guild channels, your first message is already a Discord reply to the trigger, so the recipient is clear without a text mention.

Do not mention the latest author just because replying, agreeing, answering, or addressing their point. Say the sentence normally.

Use a direct user mention only when the response explicitly needs to ping or call out that user: the user asked to be pinged/mentioned, asked you to address someone else, or ambiguity would break the reply.

Use `<@author_id>` only when that exact ID appears as a message `author_id` in the transcript; otherwise use the plain name. Write Discord mentions as raw `<@author_id>` syntax, not escaped text like `&lt;@author_id&gt;`.
